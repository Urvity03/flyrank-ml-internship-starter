# AI Toolkit Verification Guide

This guide documents the verification of the required free AI toolkit for the FlyRank Applied Search Intelligence track.

---

## 1. Required AI Tools & Verification Status

| Tool | Core Purpose in Track | Verification Status | Verified Access Method |
|---|---|---|---|
| **Claude (Anthropic)** | Complex reasoning, portfolio tutoring, code critique, and architecture pressure-testing | ✅ **Verified & Active** | Used to configure project `Urvi-AI-Portfolio-Tutor` and execute the FL-01 pressure test. |
| **ChatGPT (OpenAI)** | Code drafting, alternative algorithmic explanations, and quick syntax lookup | ⚠️ **Manual User Check** | Log in at [chatgpt.com](https://chatgpt.com) and test a standard prompt. |
| **Gemini (Google)** | Long-context document synthesis, multimodal analysis, and Google Search grounding | ⚠️ **Manual User Check** | Log in at [gemini.google.com](https://gemini.google.com) and test a standard prompt. |
| **Perplexity** | Fast technical search, citation lookup, and library documentation reference | ⚠️ **Manual User Check** | Log in at [perplexity.ai](https://perplexity.ai) and test a search query. |

---

## 2. Verification Steps for User

1. Open each tool URL in your browser.
2. Verify you can send a basic query.
3. Note the verification date on your personal tracking board.
